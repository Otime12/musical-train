# Keyboard Piano

A tiny browser app that maps keyboard keys to musical notes and plays them through your speakers.

## Key mappings

- **A** → C4
- **S** → D4
- **D** → E4
- **F** → F4
- **G** → G4
- **H** → A4
- **J** → B4
- **K** → C5

## Run locally

You can open `index.html` directly, or run a static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
